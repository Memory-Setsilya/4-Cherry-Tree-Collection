# 4-Cherry-Tree-Collection
This collection consists of 4 digital resources (websites) of metadata standards created from 1994 to present.

-[Categories for the Collection of Works of Art](https://www.getty.edu/publications/categories-description-works-art/)

-[ISO 15836-2:2019(en)](https://www.iso.org/obp/ui/#iso:std:iso:15836:-2:ed-1:v1:en)

-[IPTC Photo Metadata Working Group](https://www.iptc.org/std/photometadata/specification/IPTC-PhotoMetadata-2025.1.html)

-[Metadata Encoding & Transfer Standard](https://www.loc.gov/standards/mets/mets-schemadocs.html)
